# Responsive Wells Fargo Page

## Overview
A responsive web page design for Wells Fargo, supporting mobile, tablet, and desktop devices.

## Features
- Responsive layout
- Mobile-first design
- Adaptive typography
- Flexible background image
- Viewport meta tag for optimal rendering

## Technologies
- HTML5
- CSS3
- Responsive Design Techniques

## Getting Started
1. Clone the repository
2. Open `index.html` in a web browser

## Responsive Breakpoints
- Mobile: Up to 767px
- Tablet: 768px - 1024px
- Desktop: 1025px and above
